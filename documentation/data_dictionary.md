# Data Dictionary — UrbanTransit IQ

Primary keys **bold**; foreign keys noted. Generated by
`data_generator/generate_dataset.py` (seed 20260928).

## raw_data/routes.csv (100 rows)
| column | type | description |
|---|---|---|
| **route_id** | str | R001…R100 |
| route_name | str | human-readable line name |
| origin_area / destination_area | str | served areas |
| distance_km | float | route length |
| n_stops | int | stops on the route |
| scheduled_headway_min | int | planned headway |
| base_demand | int | demand weight used by the generator |
| archetype | str | generator archetype (high_performing / overcrowded / unreliable / underutilized / low_performing) — ground truth for validating classification |

## raw_data/stops.csv (500) — **stop_id**, stop_name, zone, lat, lon, has_shelter
## raw_data/route_stops.csv — route_id→routes, stop_id→stops, stop_sequence
## raw_data/vehicles.csv (250) — **vehicle_id**, vehicle_type, capacity, in_service_since, status
## raw_data/passengers.csv (50,000) — **passenger_id**, segment, home_zone, card_type, signup_date
## raw_data/service_calendar.csv (363) — **service_date**, day_of_week, is_weekend, is_holiday, special_event

## raw_data/trips.csv (510,510)
| column | type | description |
|---|---|---|
| **trip_id** | str | T0000001… |
| route_id / vehicle_id | FK | → routes / vehicles |
| direction | str | inbound \| outbound |
| service_date | date | operating day |
| sched_/actual_departure, sched_/actual_arrival | datetime | planned vs observed |
| sched_travel_min | float | planned travel time |
| delay_min | float | arrival delay (negative = early) |
| status | str | completed \| cancelled |

## raw_data/tickets.csv (2,061,940)
**ticket_id**, passenger_id FK, trip_id FK, route_id FK, scan_time, fare, channel

## raw_data/passenger_counts.csv (504,339)
**count_id**, trip_id FK, boarded, alighted, peak_load, capacity, occupancy_pct

## raw_data/delays.json (371,834) — **delay_id**, trip_id FK, route_id FK, delay_min, reason, recorded_at
## raw_data/gps_events.csv (40,000 sample) — **event_id**, trip_id, vehicle_id, ts, lat, lon, speed_kmh

## parquet_data/trips_enriched.parquet (504,238 × 37, partitioned by month)
All trip columns + counts + route/vehicle attributes + engineered features:
dep_hour, day_of_week, is_weekend, is_peak, actual_travel_min,
schedule_deviation_min, route_delay_7d, route_occ_7d, route_demand_7d
(leak-safe: previous-day 7-day rolling), occ_dev_7d.

## parquet_data/route_stats.parquet (100)
demand, trips, occupancy, avg_delay, on_time, p90_delay, overload_events,
reliability, score (0-100), classification (5 classes), cluster (K-Means).

occupancy_bands, od_zone_matrix, forecast_history/forecast_future,
high_risk_trips, dual_pipeline_comparison.
